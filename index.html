모몽가 데스크 버디

바탕화면 창 위를 돌아다니며 오늘 일정을 알려주고, 간식을 조르고, 날씨·뉴스 얘기를 하는 작은 날다람쥐. 설치부터 AI 수다 켜기까지 10분이면 끝나요.

Mac 다운로드내 컴퓨터Intel · Apple Silicon 둘 다 · zip 180MB Windows 다운로드내 컴퓨터Windows 10 · 11 · 설치 없이 바로 실행 · 75MB

구글 드라이브에서 받아져요. "바이러스 검사를 할 수 없습니다" 화면이 뜨면 무시하고 다운로드를 누르면 돼요.

브라우저가 "차단됨" 또는 "위험할 수 있는 파일"이라고 하면서명 없는 새 파일이라 그래요. Edge: 오른쪽 위 다운로드 목록에서 항목에 마우스 → ⋯ → 유지 → 자세히 표시 → 그래도 유지. Chrome: 다운로드 아이콘 → 항목의 ⋮ → 그래도 다운로드(또는 보관).

버튼이 아예 반응이 없으면 드라이브에서 직접 받기: Mac · Windows (열리면 오른쪽 위 다운로드 아이콘)

1. 설치하고 켜기

처음 열 때 경고가 한 번 떠요. 앱이 위험해서가 아니라, 개발자 등록(유료)을 안 한 개인 제작 앱이라 그래요. 아래대로 하면 한 번만 넘기면 끝.

  1. 다운로드한 DeskBuddy-Mac.zip을 더블클릭해서 풀기

    Safari는 자동으로 풀어줘요. 이미 Desk Buddy.app이 보이면 다음으로.

  2. Desk Buddy.app을 응용 프로그램 폴더로 끌어다 놓기

    Finder 왼쪽 목록에 있어요. 다운로드 폴더에 둔 채로 써도 되지만 나중에 찾기 힘들어요.

  3. 앱을 더블클릭 → "Apple에서 악성 소프트웨어가 없는지 확인할 수 없습니다" 창이 뜨면 완료 누르기

    "휴지통으로 이동"은 누르지 마세요. 아직 안 열리는 게 정상이에요.

  4. 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래로 내려서 그대로 열기 클릭 → Mac 비밀번호 입력

    이 버튼은 3번에서 한 번 실행해 봐야 나타나요. 한 번만 하면 다음부턴 그냥 열려요.

  5. 화면 위쪽 메뉴바에 작은 모몽가 아이콘이 생기면 성공

    아이콘을 누르면 설정·말 걸기·간식 주기·종료 메뉴가 나와요. 독(Dock)에는 안 보이는 게 정상이에요.

  1. 다운로드한 DeskBuddy-Windows.exe를 더블클릭

    설치 과정이 없어요. 파일 하나가 곧 앱이라 바탕화면 같은 데 두고 쓰면 돼요.

  2. 파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행

    "추가 정보"가 작은 글씨 링크라 잘 안 보여요. 누르면 "실행" 버튼이 나타나요.

  3. 처음엔 압축을 푸느라 10~20초 걸려요. 기다리기

    두 번째부터는 바로 떠요.

  4. 화면 오른쪽 아래 트레이(시계 옆 ^ 표시 안)에 모몽가 아이콘이 생기면 성공

    아이콘을 오른쪽 클릭하면 설정·말 걸기·간식 주기·종료 메뉴가 나와요. 작업 표시줄에는 안 보여요.

백신이 막으면서명 없는 새 프로그램이라 간혹 백신이 "알 수 없는 앱"으로 잡아요. 그럴 땐 백신에서 "허용" 또는 "예외 추가"를 눌러주세요.

2. AI 수다 켜기 (무료, 5분)

키를 안 넣어도 일정·간식·아침 날씨 한마디는 돌아가요. 키를 넣으면 모몽가가 말을 걸고 대답하고 뉴스 얘기를 해요. 구글 계정만 있으면 되고, 카드 등록은 없어요. 돈이 나갈 일이 없어요.

  1. 브라우저에서 aistudio.google.com/apikey 열기 → 구글 계정으로 로그인

    처음이면 이용약관 동의 화면이 나와요. 체크하고 계속.

  2. 파란 API 키 만들기 버튼 클릭

    프로젝트를 고르라고 하면 새 프로젝트에서 키 만들기 같은 기본 선택지를 그대로 누르면 돼요. 이름은 아무거나.

  3. AIza…로 시작하는 긴 글자가 키예요. 복사 누르기

    이 키는 비밀번호 같은 거예요. 다른 사람한테 보내지 마세요. 잃어버리면 같은 페이지에서 새로 만들면 돼요.

  4. 모몽가 아이콘(Mac은 메뉴바, Windows는 트레이) → 설정… → 아래 🤖 AI 수다 칸

    드롭다운은 Google Gemini (무료)가 기본으로 선택돼 있어요. 그대로 두세요.

  5. 키 칸에 붙여넣기 → 저장

    "저장됨"으로 바뀌면 끝. 키가 틀리면 "키가 맞지 않아요"라고 알려줘요. 그러면 3번에서 다시 복사.

  6. 모몽가를 클릭 → 말 걸기 → 아무 말이나 해보기

    대답하면 성공. 이제 4~10분마다 혼자 말도 걸어요.

자주 묻는 것

정말 돈 안 나가요?

네. Gemini 무료 등급은 카드 등록 자체를 안 하니 청구될 방법이 없어요. 대신 하루에 쓸 수 있는 횟수 한도가 있어서, 넘으면 모몽가가 "무료는 한도가 있다고!!" 하고 다음 날까지 쉬어요. 이 앱이 쓰는 양으로는 거의 안 걸려요.

대화 내용은 어디로 가요?

말 걸기·뉴스 코멘트는 구글 Gemini 서버로 가요. 무료 등급은 구글이 서비스 개선에 쓸 수 있으니, 비밀번호나 민감한 얘기는 안 하는 게 좋아요. 키는 내 컴퓨터에만 저장되고 다른 데로 안 보내요.

경고창이 뜨는 게 찜찜해요

애플·마이크로소프트에 개발자 등록(연 10만 원 넘는 유료)을 안 한 개인 제작 앱은 전부 이 경고가 떠요. 앱 안에는 캐릭터 그림과 일정 코드뿐이고, 인터넷은 날씨·뉴스·AI 세 군데만 접속해요.

끄고 싶어요 / 지우고 싶어요

모몽가 아이콘 → 종료. 완전히 지우려면 Mac은 응용 프로그램의 앱을 휴지통으로, Windows는 exe 파일을 삭제하면 끝이에요.

컴퓨터 켤 때 자동으로 뜨게 하려면

모몽가 아이콘 → 로그인 시 자동 실행 체크.

너무 커요 / 괴물이 거슬려요

설정에서 작게 보기 (0.5배), 괴물 흐리게, 모몽가·괴물 각각 켜기·끄기가 있어요.
